函数是**可复用**的代码块，用于封装特定功能。通过定义函数，可以避免重复代码，提高程序的可读性和可维护性。

| Python | JavaScript 对应 |
| ------ | ------- |
| `def` 定义函数 | `function` / 箭头函数 |
| 位置参数 | 普通形参 |
| 默认参数 | 默认参数 |
| 关键字参数 | 命名参数对象（无原生关键字传参） |
| `*args` | rest 参数 `...args` |
| `**kwargs` | rest 对象 `...kwargs` 或单独传对象 |
| `return` | `return` |
| 多返回值（元组） | 返回数组后解构 |
| Docstring | JSDoc 注释 |

## 定义函数

使用 `def` 关键字定义函数：

```python
# 定义一个简单函数
def greet():
  print("Hello, World!")

# 调用函数
greet()  # Hello, World!
```

JavaScript 类比：

```js
// 函数声明
function greet() {
  console.log("Hello, World!")
}

// 箭头函数
const greet2 = () => {
  console.log("Hello, World!")
}

greet()   // Hello, World!
greet2()  // Hello, World!
```

## 参数

### 位置参数

按照定义时的**顺序**传递参数：

```python
def add(a, b):
  return a + b

result = add(3, 5)
print(result)  # 8
```

JavaScript 类比：

```js
const add = (a, b) => a + b

const result = add(3, 5)
console.log(result)  // 8
```

### 默认参数

为参数指定**默认值**，调用时可省略：

```python
def greet(name, greeting="Hello"):
  print(f"{greeting}, {name}!")

greet("Alice")              # Hello, Alice!
greet("Bob", "Hi")          # Hi, Bob!
```

JavaScript 类比：

```js
const greet = (name, greeting = "Hello") => {
  console.log(`${greeting}, ${name}!`)
}

greet("Alice")         // Hello, Alice!
greet("Bob", "Hi")     // Hi, Bob!
```

**注意：** 默认参数必须放在非默认参数后面。

```python
# 错误示例
# def greet(greeting="Hello", name):  # SyntaxError!
#   pass
```

JavaScript 类比：

```js
// 同样非法：默认参数不能出现在必填参数前面
// function greet(greeting = "Hello", name) {}  // SyntaxError
```

### 关键字参数

通过**参数名**传递，顺序可以任意：

```python
def person_info(name, age, city):
  print(f"{name}, {age}岁, 来自{city}")

# 关键字参数，顺序无关
person_info(age=25, city="北京", name="Alice")
# Alice, 25岁, 来自北京
```

**JavaScript 无直接对应。** 无原生关键字传参；常用**对象参数**模拟：

```js
const personInfo = ({ name, age, city }) => {
  console.log(`${name}, ${age}岁, 来自${city}`)
}

// 对象属性顺序无关
personInfo({ age: 25, city: "北京", name: "Alice" })
// Alice, 25岁, 来自北京
```

**混合使用：** 位置参数在前，关键字参数在后。

```python
person_info("Alice", age=25, city="北京")  # 正确
# person_info(name="Alice", 25, "北京")   # 错误！位置参数不能在关键字参数后
```

JavaScript 类比（混合写法需自行约定）：

```js
// 常见写法：前面位置参数 + 最后传配置对象
const personInfo = (name, { age, city }) => {
  console.log(`${name}, ${age}岁, 来自${city}`)
}

personInfo("Alice", { age: 25, city: "北京" })  // 正确
// personInfo({ name: "Alice" }, 25, "北京")   // 不符合约定，语义错乱
```

### 可变参数

#### `*args` —— 接收任意数量的位置参数

```python
def sum_all(*args):
  total = 0
  for num in args:
    total += num
  return total

# 调用
print(sum_all(1, 2, 3))     # 6
print(sum_all(1, 2, 3, 4))  # 10
print(sum_all())            # 0
```

JavaScript 类比：

```js
const sumAll = (...args) => {
  let total = 0
  for (const num of args) {
    total += num
  }
  return total
}

console.log(sumAll(1, 2, 3))     // 6
console.log(sumAll(1, 2, 3, 4))  // 10
console.log(sumAll())            // 0
```

**`args` 的本质：** 函数内部是一个**元组**。

```python
def show_args(*args):
  print(type(args))  # <class 'tuple'>
  print(args)        # (1, 2, 3)

show_args(1, 2, 3)
```

JavaScript 类比：

```js
const showArgs = (...args) => {
  console.log(Array.isArray(args))  // true —— JavaScript 里是真正的数组
  console.log(args)                 // [1, 2, 3]
}

showArgs(1, 2, 3)
```

#### `**kwargs` —— 接收任意数量的关键字参数

```python
def print_info(**kwargs):
  for key, value in kwargs.items():
    print(f"{key}: {value}")

# 调用
print_info(name="Alice", age=25, city="北京")
# name: Alice
# age: 25
# city: 北京
```

**JavaScript 无直接对应。** 无 `**kwargs`；通常显式接收一个对象，或用 rest 对象解构：

```js
const printInfo = (kwargs) => {
  for (const [key, value] of Object.entries(kwargs)) {
    console.log(`${key}: ${value}`)
  }
}

printInfo({ name: "Alice", age: 25, city: "北京" })
// name: Alice
// age: 25
// city: 北京
```

**`kwargs` 的本质：** 函数内部是一个**字典**。

```python
def show_kwargs(**kwargs):
  print(type(kwargs))  # <class 'dict'>
  print(kwargs)        # {'name': 'Alice', 'age': 25}

show_kwargs(name="Alice", age=25)
```

JavaScript 类比：

```js
const showKwargs = (kwargs) => {
  console.log(typeof kwargs)  // 'object'
  console.log(kwargs)         // { name: 'Alice', age: 25 }
}

showKwargs({ name: "Alice", age: 25 })
```

### 参数顺序规则

定义函数时，参数必须按以下顺序：

```python
def func(位置参数, 默认参数, *args, **kwargs):
  pass

# 示例
def demo(a, b=2, *args, **kwargs):
  print(f"a={a}, b={b}")
  print(f"args={args}")
  print(f"kwargs={kwargs}")

demo(1, 3, 4, 5, x=10, y=20)
# a=1, b=3
# args=(4, 5)
# kwargs={'x': 10, 'y': 20}
```

**JavaScript 无直接对应。** 常见约定：位置参数 → 默认参数 → `...args` → 最后传一个对象当 kwargs：

```js
const demo = (a, b = 2, ...rest) => {
  const last = rest.at(-1)
  const hasKwargs = last && typeof last === "object" && !Array.isArray(last)
  const kwargs = hasKwargs ? rest.pop() : {}
  console.log(`a=${a}, b=${b}`)
  console.log("args=", rest)
  console.log("kwargs=", kwargs)
}

demo(1, 3, 4, 5, { x: 10, y: 20 })
// a=1, b=3
// args= [4, 5]
// kwargs= { x: 10, y: 20 }
```

## 返回值

### 使用 return

函数通过 `return` 返回结果：

```python
def square(x):
  return x ** 2

result = square(4)
print(result)  # 16
```

JavaScript 类比：

```js
const square = (x) => x ** 2

const result = square(4)
console.log(result)  // 16
```

### 多返回值

Python 函数可以**同时返回多个值**（实际是返回元组）：

```python
def min_max(numbers):
  return min(numbers), max(numbers)

minimum, maximum = min_max([3, 1, 4, 1, 5])
print(minimum)  # 1
print(maximum)  # 5

# 本质上返回的是元组
result = min_max([3, 1, 4])
print(result)       # (1, 4)
print(type(result)) # <class 'tuple'>
```

JavaScript 类比：

```js
const minMax = (numbers) => [Math.min(...numbers), Math.max(...numbers)]

const [minimum, maximum] = minMax([3, 1, 4, 1, 5])
console.log(minimum)  // 1
console.log(maximum)  // 5

// 本质上返回的是数组
const result = minMax([3, 1, 4])
console.log(result)             // [1, 4]
console.log(Array.isArray(result)) // true
```

### 没有 return

如果函数没有 `return`，默认返回 `None`：

```python
def say_hello():
  print("Hello")

result = say_hello()  # Hello
print(result)         # None
```

JavaScript 类比：

```js
const sayHello = () => {
  console.log("Hello")
}

const result = sayHello()  // Hello
console.log(result)        // undefined  ↔ None
```

## 文档字符串（Docstring）

用三引号编写函数的说明文档：

```python
def calculate_bmi(weight, height):
  """
  计算 BMI 指数。

  参数:
    weight: 体重，单位千克
    height: 身高，单位米

  返回:
    BMI 值
  """
  return weight / (height ** 2)

# 查看文档
print(calculate_bmi.__doc__)
```

JavaScript 类比（JSDoc，运行时一般不可直接读）：

```js
/**
 * 计算 BMI 指数。
 * @param {number} weight - 体重，单位千克
 * @param {number} height - 身高，单位米
 * @returns {number} BMI 值
 */
const calculateBmi = (weight, height) => weight / (height ** 2)

// JavaScript 无内置 __doc__；文档主要给 IDE / 工具用
console.log(calculateBmi(70, 1.75))
```

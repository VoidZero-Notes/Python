## 语言基本特征

| 特征 | Python | JavaScript 对应 |
| ---- | ------ | ------- |
| 执行方式 | **解释型**（也可编译为字节码） | **解释型**（引擎 JIT 优化） |
| 类型检查 | **强类型**（不允许隐式混乱运算，如 `"1" + 2` 报错） | **弱类型**（常发生隐式转换，如 `"1" + 2` → `"12"`） |
| 类型绑定 | **动态类型**（运行时确定类型） | **动态类型**（运行时确定类型） |
| 编程范式 | **面向对象**（一切皆对象） | **多范式**（面向对象 + 函数式等） |
| 代码块 | **缩进**表示代码块 | **花括号 `{}`** 表示代码块 |

```python
print(type(0x2A))     # <class 'int'>

print(type(1.2e-3))   # <class 'float'>

# 布尔值
print(type(True))     # <class 'bool'>
print(type(False))    # <class 'bool'>

print(type('World'))  # <class 'str'>

# 空值
print(type(None))     # <class 'NoneType'>
```

注意：`type`函数返回的不是字符串，而是类型对象

```python
print(type(42) == int) # True
```

JavaScript 类比：

```js
// typeof 返回字符串（注意：null 的历史坑）
console.log(typeof 42)        // "number"
console.log(typeof 3.14)      // "number"
console.log(typeof true)      // "boolean"

console.log(typeof 42 === "number") // true
```

## 变量

### 变量定义

Python是动态类型语言，变量无需声明类型，直接赋值即可创建。

```python
# 变量赋值
name = "Alice"      # 字符串
age = 25            # 整数
pi = 3.14159        # 浮点数
is_valid = True     # 布尔值
```

JavaScript 类比：

```js
// 推荐用 const / let（避免 var）
const name = "Alice"   // 字符串（之后不再重新赋值时用 const）
let age = 25           // 整数（可能再改用 let）
const pi = 3.14159     // 浮点数
const isValid = true   // 布尔值
```

### 变量命名规则

| 规则 | 说明 | 示例 | JavaScript 对应 |
| ---- | ---- | ---- | ------- |
| 字母/下划线开头 | 变量名必须以字母或下划线开头 | `name`, `_value` | 相同；也可用 `$` 开头（如 `$el`） |
| 区分大小写 | `Name` 和 `name` 是不同的变量 | `Name = 1`, `name = 2` | 相同 |
| 不能是关键字 | 不能使用Python保留字 | `if`, `for`, `class` 等 | 不能使用 JavaScript 保留字（`if`、`class`、`const` 等） |
| 只能包含字母/数字/下划线 | 不能包含空格或特殊字符 | `user_name`, `value2` | 字母/数字/`_`/`$`；不能含空格或 `-` |

**关键字（不能作为变量名）：**
`False`, `None`, `True`, `and`, `as`, `assert`, `async`, `await`, `break`, `class`, `continue`, `def`, `del`, `elif`, `else`, `except`, `finally`, `for`, `from`, `global`, `if`, `import`, `in`, `is`, `lambda`, `nonlocal`, `not`, `or`, `pass`, `raise`, `return`, `try`, `while`, `with`, `yield`

```python

_age = 25
MAX_SIZE = 100
value2 = 3.14

# 无效命名（会报错）
# 2value = 10      # 数字开头
# user-name = "a"  # 包含连字符
# class = 5        # 关键字
```

JavaScript 类比：

```js
// 有效命名
const userName = "张三"
const _age = 25
const MAX_SIZE = 100
const value2 = 3.14

// 无效命名（会报错）
// const 2value = 10      // 数字开头
// const user-name = "a"  // 包含连字符
// const class = 5        // 关键字
```

## 字符串格式化（f-string）

Python 3.6+ 引入了 f-string（格式化字符串字面量），是最简洁、最常用的字符串格式化方式。

在字符串前加 `f` 或 `F`，在花括号 `{}` 中直接嵌入变量或表达式：

```python
name = "Alice"
age = 25
print(f"姓名: {name}, 年龄: {age}")  # 姓名: Alice, 年龄: 25

# 直接嵌入表达式
a, b = 3, 5
print(f"{a} + {b} = {a + b}")       # 3 + 5 = 8
```

JavaScript 类比：

```js
const name = "Alice"
const age = 25
console.log(`姓名: ${name}, 年龄: ${age}`)  // 姓名: Alice, 年龄: 25

// 直接嵌入表达式（模板字符串）
const a = 3, b = 5
console.log(`${a} + ${b} = ${a + b}`)       // 3 + 5 = 8
```

## 运算符

### 算术运算符

| 运算符 | 名称 | int | float | str | bool | NoneType | JavaScript 对应 |
| ------ | ---- | --- | ----- | --- | ---- | -------- | ------- |
| `+` | 加法 | 数值相加 | 数值相加 | 字符串拼接 | True=1, False=0 | 不支持 | `+`（注意：`"1"+2` 会拼接成 `"12"`） |
| `-` | 减法 | 数值相减 | 数值相减 | 不支持 | True=1, False=0 | 不支持 | `-` |
| `*` | 乘法 | 数值相乘 | 数值相乘 | 字符串重复 | True=1, False=0 | 不支持 | `*`（字符串重复需用 `"Hi".repeat(3)`） |
| `/` | 除法 | 返回float | 返回float | 不支持 | True=1, False=0 | 不支持 | `/`（结果为 number） |
| `//` | 整除 | 整数除法 | 整数除法 | 不支持 | True=1, False=0 | 不支持 | 无 `//`；常用 `Math.floor(a/b)` / `Math.trunc(a/b)` |
| `%` | 取余 | 取余数 | 取余数 | 不支持 | True=1, False=0 | 不支持 | `%` |
| `**` | 幂运算 | 幂运算 | 幂运算 | 不支持 | True=1, False=0 | 不支持 | `**` 或 `Math.pow` |

```python
# int
print(5 + 3)        # 8
print(5 - 3)        # 2
print(5 * 3)        # 15
print(5 / 3)        # 1.666...
print(5 // 3)       # 1
print(5 % 3)        # 2
print(5 ** 3)       # 125

# float
print(5.0 + 3.0)    # 8.0
print(5.0 - 3.0)    # 2.0
print(5.0 * 3.0)    # 15.0
print(5.0 / 3.0)    # 1.666...
print(5.0 // 3.0)   # 1.0
print(5.0 % 3.0)    # 2.0
print(5.0 ** 3.0)   # 125.0

# str
print("Hello" + "World")  # "HelloWorld"
print("Hi" * 3)           # "HiHiHi"

# bool (True=1, False=0)
print(True + True)   # 2
print(True * 5)      # 5
print(False * 10)    # 0

# NoneType - 所有算术运算都会报错
# print(None + 1)   # TypeError
```

JavaScript 类比：

```js
// number
console.log(5 + 3)                 // 8
console.log(5 - 3)                 // 2
console.log(5 * 3)                 // 15
console.log(5 / 3)                 // 1.666...
console.log(Math.floor(5 / 3))     // 1（整除的常见写法）
console.log(5 % 3)                 // 2
console.log(5 ** 3)                // 125；也可用 Math.pow(5, 3)

// 字符串
console.log("Hello" + "World")     // "HelloWorld"
console.log("Hi".repeat(3))        // "HiHiHi"

// boolean 参与运算会先转成 1 / 0
console.log(true + true)           // 2
console.log(true * 5)              // 5
console.log(false * 10)            // 0

// null 参与运算会先转成 0（与 Python 不同）
console.log(null + 1)              // 1
```

> **JavaScript 无直接对应。** Python 的 `//` 是地板除。JavaScript 常见写法：`Math.floor(a / b)`（向负无穷取整）或 `Math.trunc(a / b)`（向 0 截断）。负数时二者可能不同，例如 `-5 // 3` 在 Python 为 `-2`，`Math.trunc(-5/3)` 为 `-1`。

### 比较运算符

| 运算符 | 名称 | int | float | str | bool | NoneType | JavaScript 对应 |
| ------ | ---- | --- | ----- | --- | ---- | -------- | ------- |
| `==` | 等于 | 数值比较 | 数值比较 | 内容比较 | True\==1, False==0 | None==None | `==`（会类型转换）/ `===`（严格相等，更常用） |
| `!=` | 不等于 | 数值比较 | 数值比较 | 内容比较 | True!=0 | None!=非None | `!=` / `!==` |
| `<` | 小于 | 数值比较 | 数值比较 | 字典序比较 | True=1, False=0 | 不支持 | `<` |
| `>` | 大于 | 数值比较 | 数值比较 | 字典序比较 | True=1, False=0 | 不支持 | `>` |
| `<=` | 小于等于 | 数值比较 | 数值比较 | 字典序比较 | True=1, False=0 | 不支持 | `<=` |
| `>=` | 大于等于 | 数值比较 | 数值比较 | 字典序比较 | True=1, False=0 | 不支持 | `>=` |

```python
# int
print(5 == 5)       # True
print(5 != 3)       # True
print(5 > 3)        # True

# float
print(5.0 == 5.0)   # True
print(5.0 != 3.0)   # True
print(5.0 > 3.0)    # True

# str (按字典序/ASCII码比较)
print("abc" == "abc")     # True
print("abc" != "def")     # True
print("abc" < "def")      # True
print("A" < "a")          # True (A=65, a=97)

# bool
print(True == 1)          # True
print(False == 0)         # True
print(True > False)       # True

# NoneType
print(None == None)       # True
print(None != 0)          # True
print(None != False)      # True
# print(None > 0)         # TypeError
```

JavaScript 类比：

```js
// number
console.log(5 === 5)       // true
console.log(5 !== 3)       // true
console.log(5 > 3)         // true

// string（字典序/Unicode 码点比较）
console.log("abc" === "abc")  // true
console.log("abc" !== "def")  // true
console.log("abc" < "def")    // true
console.log("A" < "a")        // true (A=65, a=97)

// boolean 与数字：== 会转换，=== 不会
console.log(true == 1)        // true
console.log(true === 1)       // false（推荐用 ===）
console.log(true > false)     // true

// null
console.log(null === null)    // true
console.log(null != 0)        // true（注意 == 时有特殊规则）
console.log(null == undefined) // true（宽松相等）
console.log(null === undefined) // false
```

### 链式比较

Python 支持**链式比较**，可以像数学公式一样连续写比较运算符：

```python
x = 5

# 传统写法（其他语言）
print(x > 1 and x < 10)   # True

# Python 链式比较（更简洁）
print(1 < x < 10)         # True
print(1 < x <= 5)         # True
print(5 <= x < 10)        # True
print(1 < x < 3)          # False

# 甚至可以更复杂
print(1 < x < 10 < 100)   # True
```

**等价规则：** `a < b < c` 等价于 `a < b and b < c`，但**只计算一次** `b`。

> **JavaScript 无直接对应。** `1 < x < 10` 在 JavaScript 中会先算 `1 < x` 得到布尔值，再与 `10` 比较，结果常不符合直觉。常见写法：`x > 1 && x < 10`。

```js
const x = 5

console.log(x > 1 && x < 10)   // true（推荐）
console.log(1 < x && x < 10)   // true
console.log(1 < x && x <= 5)   // true

// 错误示范：链式写法在 JavaScript 中含义不同
console.log(1 < x < 10)        // true（碰巧对），实际是 (1 < x) < 10 → true < 10 → 1 < 10
console.log(1 < x < 3)         // true（错误！），实际是 (1 < x) < 3 → true < 3 → 1 < 3
```

### 海象运算符（:=）

Python 3.8 引入的**赋值表达式**，可以在表达式中同时进行赋值和求值。

```python
# 传统写法：先赋值，再判断
line = input("输入: ")
while line != "quit":
  print(f"你输入了: {line}")
  line = input("输入: ")

# 使用海象运算符：赋值和判断合二为一
while (line := input("输入: ")) != "quit":
  print(f"你输入了: {line}")
```

**注意：** 海象运算符是 Python 3.8 的新特性，老版本不支持。

**JavaScript / NodeJS 无直接对应。** 常见写法：先赋值再判断（NodeJS 用 `readline`）。

```js
import readline from "node:readline/promises"
import { stdin as input, stdout as output } from "node:process"

const rl = readline.createInterface({ input, output })

// 常见写法：先赋值，再判断
let line = await rl.question("输入: ")
while (line !== "quit") {
  console.log(`你输入了: ${line}`)
  line = await rl.question("输入: ")
}

rl.close()
```

### 逻辑运算符

| 运算符 | 说明 | 返回值规则 | JavaScript 对应 |
| ------ | ---- | ---------- | ------- |
| `and` | 逻辑与 | 第一个为False则返回第一个，否则返回第二个 | `&&` |
| `or` | 逻辑或 | 第一个为True则返回第一个，否则返回第二个 | `||` |
| `not` | 逻辑非 | 返回True或False | `!` |

**各类型真假值：**

- 数值: `0`、`0.0`、`0j` 为 False，其他为 True
- str: `""` 为 False，其他为 True
- bool: `False` 为 False，`True` 为 True
- NoneType: `None` 为 False
- 空容器: `[]`、`{}`、`()`、`set()`、`frozenset()`、`range(0)` 等为 False；非空为 True
- 自定义类: `__bool__` 返回 False，或未定义 `__bool__` 时 `__len__` 返回 0 → False

JavaScript 中类似的假值（falsy）：`false`、`0`、`""`、`null`、`undefined`、`NaN`。  

注意：JS 中空数组 `[]`、空对象 `{}` 为真值（truthy），与 Python 不同。

```python
# int
print(0 and 5)        # 0 (0为False，返回0)
print(3 and 5)        # 5 (3为True，返回5)
print(0 or 5)         # 5 (0为False，返回5)
print(3 or 5)         # 3 (3为True，返回3)
print(not 0)          # True
print(not 5)          # False

# float
print(0.0 and 5.0)    # 0.0
print(3.0 and 5.0)    # 5.0
print(not 0.0)        # True

# str
print("" and "hello") # "" (空字符串为False)
print("hi" and "hello") # "hello"
print(not "")         # True
print(not "hello")    # False

# bool
print(True and False)  # False
print(True or False)   # True
print(not True)        # False

# NoneType
print(None and True)   # None
print(None or True)    # True
print(not None)        # True

# 空容器
print([] and [1])     # []
print([1] and [2])    # [2]
print(not [])         # True
print(not [1])        # False
print({} or {"a": 1}) # {"a": 1}
print(not {})         # True
print(not ())         # True
print(not set())      # True
```

JavaScript 类比：

```js
// number
console.log(0 && 5)         // 0
console.log(3 && 5)         // 5
console.log(0 || 5)         // 5
console.log(3 || 5)         // 3
console.log(!0)             // true
console.log(!5)             // false

// string
console.log("" && "hello")  // ""
console.log("hi" && "hello") // "hello"
console.log(!"")            // true
console.log(!"hello")       // false

// boolean
console.log(true && false)  // false
console.log(true || false)  // true
console.log(!true)          // false

// null / undefined
console.log(null && true)   // null
console.log(null || true)   // true
console.log(!null)          // true

// 空数组 / 空对象：JS 为真值（与 Python 不同）
console.log(![])            // false
console.log(!{})            // false
```

### 三元运算符（条件表达式）

Python 的三元运算符（条件表达式）是一种简洁的 `if-else` 写法，用于在一行中根据条件选择不同的值。

**语法：**

```python
结果 = 真值 if 条件 else 假值
```

```python
score = 85

# 传统写法
if score >= 60:
  result = "及格"
else:
  result = "不及格"

# 三元运算符（更简洁）
result = "及格" if score >= 60 else "不及格"
print(result)  # 及格

# 嵌套三元运算符（不推荐过度嵌套）
age = 25
category = "青年" if age < 40 else ("中年" if age < 60 else "老年")
```

JavaScript 类比：

```js
const score = 85

// 传统写法
let result
if (score >= 60) {
  result = "及格"
} else {
  result = "不及格"
}

// 三元运算符（更简洁）
const result2 = score >= 60 ? "及格" : "不及格"
console.log(result2)  // 及格

// 嵌套三元运算符（不推荐过度嵌套）
const age = 25
const category = age < 40 ? "青年" : (age < 60 ? "中年" : "老年")
```

**注意：** 三元运算符适合简单的条件判断，复杂的逻辑应使用传统的 `if-else` 结构以保持代码可读性。

## 流程控制

### 条件判断

| 语法 | 说明 | JavaScript 对应 |
| ---- | ---- | ------- |
| `if 条件:` | 条件为True时执行 | `if (条件) { ... }` |
| `elif 条件:` | 前一个条件为False且当前条件为True时执行 | `else if (条件) { ... }` |
| `else:` | 前面所有条件都为False时执行 | `else { ... }` |

```python
# 基本if-else
age = 18
if age >= 18:
  print("成年人")
else:
  print("未成年人")

# if-elif-else
score = 85
if score >= 90:
  grade = "A"
elif score >= 80:
  grade = "B"
elif score >= 60:
  grade = "C"
else:
  grade = "D"
print(f"成绩等级: {grade}")

# 单行if-else（三元表达式）
result = "通过" if score >= 60 else "不及格"
```

JavaScript 类比：

```js
// 基本 if-else
const age = 18
if (age >= 18) {
  console.log("成年人")
} else {
  console.log("未成年人")
}

// if - else if - else
const score = 85
let grade
if (score >= 90) {
  grade = "A"
} else if (score >= 80) {
  grade = "B"
} else if (score >= 60) {
  grade = "C"
} else {
  grade = "D"
}
console.log(`成绩等级: ${grade}`)

// 单行三元表达式
const result = score >= 60 ? "通过" : "不及格"
```

**注意：** Python使用缩进（通常为2个空格）表示代码块，不使用花括号。JavaScript 使用花括号 `{}` 表示代码块。

### pass占位符

`pass`是Python中的占位符语句，不执行任何操作，用于语法上需要语句但逻辑上暂时不需要的情况。

```python

  pass  # 暂时不执行任何操作

```

**JavaScript 无直接对应。** 空语句可用空块 `{}`；循环里也可写空语句 `;`（不推荐）。

```js
  // 暂时不执行任何操作
  i += 1
}

// 空代码块（占位）

  // 待实现
}
```

#### 循环控制语句

| 语句 | 作用 | JavaScript 对应 |
| ---- | ---- | ------- |
| `break` | 立即终止整个循环 | `break` |
| `continue` | 跳过当前迭代，进入下一次循环 | `continue` |

```python
# break - 找到第一个大于5的数就停止
num = 1
while num <= 10:
  if num > 5:
    print(f"找到大于5的数: {num}")
    break
  num += 1

# continue - 跳过奇数，只打印偶数
num = 0
while num < 10:
  if num % 2 != 0:
    num += 1
    continue
  print(num)  # 0, 2, 4, 6, 8
  num += 1
```

JavaScript 类比：

```js

let num = 1
while (num <= 10) {
  if (num > 5) {
    console.log(`找到大于5的数: ${num}`)
    break
  }
  num += 1
}

// continue - 跳过奇数，只打印偶数
num = 0
while (num < 10) {
  if (num % 2 !== 0) {
    num += 1
    continue

  num += 1
}
```

#### 循环else子句

循环可以带有一个`else`子句，当循环**正常结束**（没有被break中断）时执行。

```python
# while循环的else
count = 0
while count < 3:
  print(count)
  count += 1
else:
  print("while循环正常完成")

# 典型用法：查找元素
num = 1
while num <= 9:
  if num == 4:
    print("找到: 4")
    break
  num += 2  # 模拟遍历奇数1, 3, 5, 7, 9
else:
  print("未找到: 4")  # 会执行，因为4不在奇数序列中
```

**重要区别：**

- 循环被`break`中断 → **不执行**else
- 循环正常结束（包括`continue`）→ **执行**else

**JavaScript 无直接对应。** 常见写法：用 flag 变量判断是否被 `break` 中断。

```js
// 模拟 while...else：正常结束时执行一段逻辑
let count = 0
let finishedNormally = true
while (count < 3) {
  console.log(count)
  count += 1
}
if (finishedNormally) {
  console.log("while循环正常完成")
}

// 典型用法：查找元素
let num = 1
let found = false
while (num <= 9) {
  if (num === 4) {
    console.log("找到: 4")
    found = true
    break
  }
  num += 2  // 模拟遍历奇数 1, 3, 5, 7, 9
}
if (!found) {
  console.log("未找到: 4")  // 会执行，因为 4 不在奇数序列中
}
```

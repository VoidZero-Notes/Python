抽象类是**不能被实例化**的类，用于定义子类**必须实现**的接口。Python 通过 `abc` 模块提供抽象类的支持。

| Python | TypeScript 对应 |
| ------ | --------------- |
| `ABC` / 继承抽象基类 | `abstract class` |
| `@abstractmethod` | `abstract` 方法 |
| 抽象属性（`@property` + `@abstractmethod`） | `abstract get` / `abstract set` |
| 含未实现抽象成员的子类仍是抽象类 | 编译期报错（未实现则不能实例化） |
| 实例化抽象类 → 运行时 `TypeError` | 编译期报错（运行时无此强制） |

> **说明：** Python 的 `abc` 在**运行时**阻止实例化；TypeScript 的 `abstract` 主要在**编译期**检查，编译后类型会被擦除。建议在 VS Code / Cursor 中开启 `python.analysis.typeCheckingMode`，便于尽早发现未实现的抽象成员。

```python
from abc import ABC, abstractmethod

class Animal(ABC):  # 继承 ABC，表示这是一个抽象类
  @abstractmethod
  def speak(self):
    """子类必须实现这个方法"""
    pass

# animal = Animal()  # TypeError: 不能实例化抽象类

class Dog(Animal):
  def speak(self):  # 必须实现抽象方法
    print("Woof!")

dog = Dog()
dog.speak()  # Woof!
```

TypeScript 类比：

```ts
abstract class Animal {
  abstract speak(): void
}

// const animal = new Animal()  // 编译错误：不能实例化抽象类

class Dog extends Animal {
  speak() {
    console.log("Woof!")
  }
}

const dog = new Dog()
dog.speak()  // Woof!
```

## 定义抽象类

使用 `abc` 模块中的 `ABC` 类和 `@abstractmethod` 装饰器：

```python
from abc import ABC, abstractmethod

class Shape(ABC):
  @abstractmethod
  def area(self):
    """计算面积"""
    pass

  @abstractmethod
  def perimeter(self):
    """计算周长"""
    pass

  def describe(self):
    """普通方法，子类可直接使用"""
    print(f"这是一个图形，面积: {self.area()}, 周长: {self.perimeter()}")
```

TypeScript 类比：

```ts
abstract class Shape {
  abstract area(): number
  abstract perimeter(): number

  describe() {
    console.log(`这是一个图形，面积: ${this.area()}, 周长: ${this.perimeter()}`)
  }
}
```

**要点：**

- 继承 `ABC` 表示这是一个抽象类
- `@abstractmethod` 标记的方法**必须**在子类中实现
- 抽象类可以包含普通方法（有默认实现）
- 抽象类**不能**被实例化

## 抽象属性

除了抽象方法，还可以定义抽象属性：

```python
from abc import ABC, abstractmethod

class Employee(ABC):
  @property
  @abstractmethod
  def salary(self):
    """子类必须实现 salary 属性"""
    pass

class FullTimeEmployee(Employee):
  def __init__(self, monthly_salary):
    self._monthly_salary = monthly_salary

  @property
  def salary(self):
    return self._monthly_salary

emp = FullTimeEmployee(10000)
print(emp.salary)  # 10000
```

TypeScript 类比：

```ts
abstract class Employee {
  abstract get salary(): number
}

class FullTimeEmployee extends Employee {
  private _monthlySalary: number

  constructor(monthlySalary: number) {
    super()
    this._monthlySalary = monthlySalary
  }

  get salary() {
    return this._monthlySalary
  }
}

const emp = new FullTimeEmployee(10000)
console.log(emp.salary)  // 10000
```

**注意：** `@property` 和 `@abstractmethod` 的顺序**不能颠倒**（须先 `@property` 再 `@abstractmethod`）。

> **说明：** TypeScript 用 `abstract get` 声明抽象访问器，没有装饰器叠放顺序问题。

## 子类必须实现所有抽象方法

如果子类没有实现所有抽象方法，它仍然是抽象类，不能被实例化：

```python
class Rectangle(Shape):
  def __init__(self, width, height):
    self.width = width
    self.height = height

  def area(self):
    return self.width * self.height

  # 忘记实现 perimeter 方法

# rect = Rectangle(3, 4)  # TypeError: 不能实例化抽象类 Rectangle
```

TypeScript 类比：

```ts
class Rectangle extends Shape {
  constructor(private width: number, private height: number) {
    super()
  }

  area() {
    return this.width * this.height
  }

  // 忘记实现 perimeter 方法
}

// const rect = new Rectangle(3, 4)  // 编译错误：未实现抽象成员 perimeter
```

## 实际应用场景

抽象类常用于定义**插件接口**或**框架扩展点**：

```python
from abc import ABC, abstractmethod

class DataSource(ABC):
  """数据源抽象基类，所有数据源必须实现这些接口"""

  @abstractmethod
  def connect(self):
    pass

  @abstractmethod
  def read(self):
    pass

  @abstractmethod
  def close(self):
    pass

class MySQLSource(DataSource):
  def connect(self):
    print("连接 MySQL")

  def read(self):
    return "MySQL 数据"

  def close(self):
    print("关闭 MySQL 连接")

class MongoDBSource(DataSource):
  def connect(self):
    print("连接 MongoDB")

  def read(self):
    return "MongoDB 数据"

  def close(self):
    print("关闭 MongoDB 连接")

def process_data(source: DataSource):
  """统一处理数据，不关心具体数据源"""
  source.connect()
  data = source.read()
  print(f"读取到: {data}")
  source.close()

# 使用不同的数据源
process_data(MySQLSource())
process_data(MongoDBSource())
```

TypeScript 类比：

```ts
abstract class DataSource {
  abstract connect(): void
  abstract read(): string
  abstract close(): void
}

class MySQLSource extends DataSource {
  connect() {
    console.log("连接 MySQL")
  }

  read() {
    return "MySQL 数据"
  }

  close() {
    console.log("关闭 MySQL 连接")
  }
}

class MongoDBSource extends DataSource {
  connect() {
    console.log("连接 MongoDB")
  }

  read() {
    return "MongoDB 数据"
  }

  close() {
    console.log("关闭 MongoDB 连接")
  }
}

const processData = (source: DataSource) => {
  source.connect()
  const data = source.read()
  console.log(`读取到: ${data}`)
  source.close()
}

processData(new MySQLSource())
processData(new MongoDBSource())
```

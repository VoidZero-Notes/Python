Python 是一门**面向对象**的编程语言。类（Class）是创建对象的蓝图，而对象（Object）是类的具体实例。通过类和对象，可以将数据（属性）和行为（方法）封装在一起，使代码更具结构性和可复用性。

| Python | JavaScript 对应 |
| ------ | ------- |
| `class` 定义类 | `class` |
| `__init__` | `constructor` |
| 实例属性 / `self` | 实例字段 / `this` |
| 类属性 | `static` 字段（或挂在构造函数上） |
| 实例方法 | 原型方法 / 类方法 |
| `@classmethod` | **无直接对应**（常用 `static` + 传类本身） |
| `@staticmethod` | `static` 方法 |
| 单继承 / `super()` | `extends` / `super` |
| 多继承 / MRO | **无直接对应**（常用 mixin / 组合） |
| `_name` / `__name` | 约定私有 / `#private` 字段 |
| `isinstance` / `issubclass` | `instanceof` / `prototype` 链判断 |
| `type(obj)` | `typeof`（有限）/ `obj.constructor` / `Object.getPrototypeOf` |

## 定义类

使用 `class` 关键字定义类：

```python
class Dog:
  pass

# 创建实例
my_dog = Dog()
print(type(my_dog))  # <class '__main__.Dog'>
```

JavaScript 类比：

```js
class Dog {}

// 创建实例
const myDog = new Dog()
console.log(myDog.constructor.name)  // Dog
console.log(myDog instanceof Dog)    // true
```

### 使用 `type()` 动态定义类

类本身也是对象，`type()` 是创建类的内置函数。可以动态地创建类：

```python
# type(类名, (父类元组,), {属性字典})

# 定义方法
def bark(self):
  print(f"{self.name} says: Woof!")

# 动态创建 Dog 类
Dog = type("Dog", (), {"name": "Buddy", "bark": bark})

# 创建实例
my_dog = Dog()
print(my_dog.name)  # Buddy
my_dog.bark()       # Buddy says: Woof!
```

**参数说明：**

- 第一个参数：类名（字符串）
- 第二个参数：继承的父类元组
- 第三个参数：类属性和方法的字典

**实际应用场景：** 在 ORM 框架或需要根据配置动态生成类的场景中经常使用。

**JavaScript 无直接对应。** 无与 `type(name, bases, dict)` 完全等价的内置 API；常见替代：类表达式，或工厂函数动态拼装原型：

```js
const bark = function () {
  console.log(`${this.name} says: Woof!`)
}

// 用工厂动态“拼”出一个类
const createDogClass = () => {
  return class {
    name = "Buddy"
    bark = bark
  }
}

const Dog = createDogClass()
const myDog = new Dog()
console.log(myDog.name)  // Buddy
myDog.bark()             // Buddy says: Woof!
```

## 构造方法 `__init__`

`__init__` 是类的构造方法，在创建对象时自动调用，用于初始化对象的属性：

```python
class Dog:
  def __init__(self, name, age):
    self.name = name
    self.age = age

# 创建对象时传入参数
my_dog = Dog("Buddy", 3)
print(my_dog.name)  # Buddy
print(my_dog.age)   # 3
```

JavaScript 类比：

```js
class Dog {
  constructor(name, age) {
    this.name = name
    this.age = age
  }
}

const myDog = new Dog("Buddy", 3)
console.log(myDog.name)  // Buddy
console.log(myDog.age)   // 3
```

**注意：** `self` 代表对象本身，必须是第一个参数，但调用时不需要传。

> **说明：** Python 约定第一个参数叫 `self`（名字可改，但不推荐）；JavaScript 用 `this`，由调用方式决定，不出现在形参列表里。

## 实例属性与类属性

### 实例属性

每个对象独立的属性，通过 `self` 定义：

```python
class Dog:
  def __init__(self, name):
    self.name = name  # 实例属性

dog1 = Dog("Buddy")
dog2 = Dog("Max")

print(dog1.name)  # Buddy
print(dog2.name)  # Max
```

JavaScript 类比：

```js
class Dog {
  constructor(name) {
    this.name = name  // 实例属性
  }
}

const dog1 = new Dog("Buddy")
const dog2 = new Dog("Max")

console.log(dog1.name)  // Buddy
console.log(dog2.name)  // Max
```

### 类属性

所有对象共享的属性，在类内部直接定义：

```python
class Dog:
  species = "Canis familiaris"  # 类属性

  def __init__(self, name):
    self.name = name

dog1 = Dog("Buddy")
dog2 = Dog("Max")

print(dog1.species)  # Canis familiaris
print(dog2.species)  # Canis familiaris

# 修改类属性（通过类名）
Dog.species = "Canis lupus"
print(dog1.species)  # Canis lupus
```

JavaScript 类比：

```js
class Dog {
  static species = "Canis familiaris"  // 静态（类）属性

  constructor(name) {
    this.name = name
  }
}

const dog1 = new Dog("Buddy")
const dog2 = new Dog("Max")

console.log(Dog.species)  // Canis familiaris
// 注意：默认不会挂到实例上，需通过类访问
console.log(dog1.species) // undefined

Dog.species = "Canis lupus"
console.log(Dog.species)  // Canis lupus
```

**访问规则：** 实例属性通过 `self` 访问，类属性通过 `类名` 或 `self` 访问。

> **说明：** Python 实例找不到属性时会沿类查找类属性；JavaScript 的 `static` 字段只挂在类上，实例默认读不到（除非自己再挂到 `prototype` 上）。

## 实例方法

定义在类中的函数，第一个参数必须是 `self`：

```python
class Dog:
  def __init__(self, name):
    self.name = name

  def bark(self):
    print(f"{self.name} says: Woof!")

  def introduce(self):
    self.bark()  # 方法内调用其他方法
    print(f"My name is {self.name}")

my_dog = Dog("Buddy")
my_dog.bark()       # Buddy says: Woof!
my_dog.introduce()  # Buddy says: Woof! My name is Buddy
```

JavaScript 类比：

```js
class Dog {
  constructor(name) {
    this.name = name
  }

  bark() {
    console.log(`${this.name} says: Woof!`)
  }

  introduce() {
    this.bark()  // 方法内调用其他方法
    console.log(`My name is ${this.name}`)
  }
}

const myDog = new Dog("Buddy")
myDog.bark()       // Buddy says: Woof!
myDog.introduce()  // Buddy says: Woof! My name is Buddy
```

## 类方法与静态方法

### 类方法 `@classmethod`

第一个参数是 `cls`，代表类本身，可以访问或修改类属性：

```python
class Dog:
  count = 0  # 类属性：记录创建了多少只狗

  def __init__(self, name):
    self.name = name
    Dog.count += 1

  @classmethod
  def get_count(cls):
    return cls.count

dog1 = Dog("Buddy")
dog2 = Dog("Max")

print(Dog.get_count())  # 2
```

**JavaScript 无直接对应。** 没有自动传入“类本身”的 `@classmethod`；常用 `static` 方法，在方法里直接写类名（或传构造函数）：

```js
class Dog {
  static count = 0

  constructor(name) {
    this.name = name
    Dog.count += 1
  }

  static getCount() {
    return Dog.count  // 需显式写类名；子类覆盖时要注意绑定
  }
}

const dog1 = new Dog("Buddy")
const dog2 = new Dog("Max")

console.log(Dog.getCount())  // 2
```

### 静态方法 `@staticmethod`

不接收 `self` 或 `cls`，与普通函数类似，只是组织在类中：

```python
class MathUtils:
  @staticmethod
  def add(a, b):
    return a + b

  @staticmethod
  def is_even(n):
    return n % 2 == 0

print(MathUtils.add(3, 5))      # 8
print(MathUtils.is_even(4))     # True
```

JavaScript 类比：

```js
class MathUtils {
  static add(a, b) {
    return a + b
  }

  static isEven(n) {
    return n % 2 === 0
  }
}

console.log(MathUtils.add(3, 5))     // 8
console.log(MathUtils.isEven(4))     // true
```

**对比：**

| 方法类型 | 装饰器          | 第一个参数 | 访问实例属性 | 访问类属性 | JavaScript 对应 |
| -------- | --------------- | ---------- | ------------ | ---------- | ------- |
| 实例方法 | 无              | `self`     | ✓            | ✓          | 普通方法 |
| 类方法   | `@classmethod`  | `cls`      | ✗            | ✓          | **无直接对应**（多用 `static`） |
| 静态方法 | `@staticmethod` | 无         | ✗            | ✗          | `static` 方法 |

## 继承

子类继承父类的属性和方法，并可以扩展或重写：

```python
class Animal:
  def __init__(self, name):
    self.name = name

  def speak(self):
    print("Some sound")

class Dog(Animal):  # Dog 继承 Animal
  def speak(self):  # 重写父类方法
    print(f"{self.name} says: Woof!")

class Cat(Animal):
  def speak(self):
    print(f"{self.name} says: Meow!")

dog = Dog("Buddy")
cat = Cat("Kitty")

dog.speak()  # Buddy says: Woof!
cat.speak()  # Kitty says: Meow!
```

JavaScript 类比：

```js
class Animal {
  constructor(name) {
    this.name = name
  }

  speak() {
    console.log("Some sound")
  }
}

class Dog extends Animal {
  speak() {
    console.log(`${this.name} says: Woof!`)
  }
}

class Cat extends Animal {
  speak() {
    console.log(`${this.name} says: Meow!`)
  }
}

const dog = new Dog("Buddy")
const cat = new Cat("Kitty")

dog.speak()  // Buddy says: Woof!
cat.speak()  // Kitty says: Meow!
```

### 调用父类方法

使用 `super()` 调用父类的方法：

```python
class Animal:
  def __init__(self, name):
    self.name = name
    print("Animal init")

class Dog(Animal):
  def __init__(self, name, breed):
    super().__init__(name)  # 调用父类的 __init__
    self.breed = breed      # 扩展新属性
    print("Dog init")

dog = Dog("Buddy", "Golden Retriever")
print(dog.name)   # Buddy
print(dog.breed)  # Golden Retriever
```

JavaScript 类比：

```js
class Animal {
  constructor(name) {
    this.name = name
    console.log("Animal init")
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name)        // 调用父类 constructor
    this.breed = breed // 扩展新属性
    console.log("Dog init")
  }
}

const dog = new Dog("Buddy", "Golden Retriever")
console.log(dog.name)   // Buddy
console.log(dog.breed)  // Golden Retriever
```

### 多继承

Python 支持一个子类同时继承多个父类：

```python
class Flyable:
  def fly(self):
    print("I can fly!")

class Swimmable:
  def swim(self):
    print("I can swim!")

class Duck(Flyable, Swimmable):  # 同时继承 Flyable 和 Swimmable
  pass

duck = Duck()
duck.fly()   # I can fly!
duck.swim()  # I can swim!
```

**JavaScript 无直接对应。** 类只能 `extends` 一个父类；常用 mixin（混入）或组合：

```js
const Flyable = {
  fly() {
    console.log("I can fly!")
  },
}

const Swimmable = {
  swim() {
    console.log("I can swim!")
  },
}

class Duck {}
Object.assign(Duck.prototype, Flyable, Swimmable)

const duck = new Duck()
duck.fly()   // I can fly!
duck.swim()  // I can swim!
```

#### 方法解析顺序（MRO）

当多个父类有同名方法时，Python 按照 **MRO**（Method Resolution Order）顺序查找：

```python
class A:
  def hello(self):
    print("Hello from A")

class B(A):
  def hello(self):
    print("Hello from B")

class C(A):
  def hello(self):
    print("Hello from C")

class D(B, C):  # MRO: D -> B -> C -> A
  pass

d = D()
d.hello()  # Hello from B（先找到 B 的方法）

# 查看 MRO 顺序
print(D.__mro__)  # (<class 'D'>, <class 'B'>, <class 'C'>, <class 'A'>, <class 'object'>)
print(D.mro())    # 同上，与 __mro__ 等价
print(D.__bases__)  # (<class 'B'>, <class 'C'>)，直接父类
print(D.__base__)   # <class 'B'>，取 __bases__ 的第一个
```

**JavaScript 无直接对应。** 单继承只有一条原型链，没有 MRO；可用 `Object.getPrototypeOf` 查看原型链：

```js
class A {
  hello() {
    console.log("Hello from A")
  }
}

class B extends A {
  hello() {
    console.log("Hello from B")
  }
}

const b = new B()
b.hello()  // Hello from B
console.log(Object.getPrototypeOf(B) === A)  // true
```

#### `super()` 在多继承中的行为

`super()` 按照 MRO 顺序调用**下一个**类的方法，不一定是直接父类：

```python
class A:
  def __init__(self):
    print("A init")

class B(A):
  def __init__(self):
    print("B init")
    super().__init__()  # 调用 C 的 __init__，不是 A

class C(A):
  def __init__(self):
    print("C init")
    super().__init__()  # 调用 A 的 __init__

class D(B, C):
  def __init__(self):
    print("D init")
    super().__init__()  # 调用 B 的 __init__

D()
# 输出：
# D init
# B init
# C init
# A init
```

**注意：** 多继承虽然强大，但过度使用会使代码难以维护。通常优先考虑组合（Composition）代替多继承。

> **说明：** JavaScript 的 `super` 只沿单继承原型链调用父类；没有“按 MRO 找下一个类”的行为。

## 访问控制

Python 没有严格的私有/公有，但以下划线约定访问权限：

| 命名方式 | 含义             | 访问建议         | JavaScript 对应 |
| -------- | ---------------- | ---------------- | ------- |
| `name`   | 公有             | 可自由访问       | 普通属性 |
| `_name`  | 保护（约定）     | 建议不直接访问   | 约定 `_name`（无强制） |
| `__name` | 私有（名称改写） | 外部难以直接访问 | `#name` 真正私有字段 |

```python
class BankAccount:
  def __init__(self, owner, balance):
    self.owner = owner          # 公有
    self._balance = balance     # 保护
    self.__password = "123456"  # 私有（名称改写为 _BankAccount__password）

  def deposit(self, amount):
    if amount > 0:
      self._balance += amount

  def get_balance(self):
    return self._balance

account = BankAccount("Alice", 1000)
print(account.owner)      # Alice
print(account._balance)   # 1000（可以访问，但不建议）
# print(account.__password)  # AttributeError！
print(account._BankAccount__password)  # 123456（强行访问）
```

JavaScript 类比：

```js
class BankAccount {
  #password  // 真正私有字段

  constructor(owner, balance) {
    this.owner = owner
    this._balance = balance  // 约定“保护”，仍可外部访问
    this.#password = "123456"
  }

  deposit(amount) {
    if (amount > 0) {
      this._balance += amount
    }
  }

  getBalance() {
    return this._balance
  }
}

const account = new BankAccount("Alice", 1000)
console.log(account.owner)     // Alice
console.log(account._balance)  // 1000（可以访问，但不建议）
// console.log(account.#password)  // SyntaxError！类外无法访问
```

**注意：** Python 的访问控制基于约定，不是强制（`__name` 只是名称改写）。JavaScript 的 `#` 私有字段在语法层面不可从类外访问。

命名规则适用于所有成员（属性、方法等）：

```python
class A:
  _a = 1      # 约定私有，外部仍可访问，多数场景用它
  __a = 2     # 名称改写，外部无法直接访问 __a
  __a__ = 3   # 首尾双下划线：特殊/魔术成员，通常留给系统内置

  @classmethod
  def test(cls):
    print(cls._a, cls.__a, cls.__a__)  # 类内部可访问全部

A.test()  # 1 2 3
print(A._a, A.__a__)  # 1 3
# print(A.__a)        # AttributeError，需用 A._A__a 强行访问
```

## 常见操作

### 内置属性

Python 的类和对象有一些内置属性，用于获取元信息：

| 属性        | 说明                     | JavaScript 对应 |
| ----------- | ------------------------ | ------- |
| `__class__` | 对象所属的类             | `obj.constructor` / `Object.getPrototypeOf` |
| `__bases__` | 类的所有直接父类（元组） | `Object.getPrototypeOf(Class)`（仅单继承） |
| `__base__`  | 类的第一个直接父类       | 同上 |
| `__dict__`  | 对象或类的属性字典       | 无完全等价；可用枚举自有属性 |

```python
class Animal:
  pass

class Dog(Animal):
  species = "Canis familiaris"

  def __init__(self, name):
    self.name = name

dog = Dog("Buddy")

# __class__: 查看对象所属的类
print(dog.__class__)           # <class '__main__.Dog'>
print(dog.__class__.__name__)  # Dog

# __bases__: 查看类的所有直接父类
print(Dog.__bases__)           # (<class '__main__.Animal'>,)

# __base__: 查看类的第一个直接父类
print(Dog.__base__)            # <class '__main__.Animal'>

# __dict__: 查看对象的属性字典
print(dog.__dict__)            # {'name': 'Buddy'}

# __dict__: 查看类的属性字典（包含方法）
print(Dog.__dict__.keys())     # dict_keys([..., 'species', '__init__', ...])
```

JavaScript 类比：

```js
class Animal {}

class Dog extends Animal {
  static species = "Canis familiaris"

  constructor(name) {
    super()
    this.name = name
  }
}

const dog = new Dog("Buddy")

console.log(dog.constructor.name)              // Dog
console.log(Object.getPrototypeOf(Dog).name)   // Animal
console.log(Object.getOwnPropertyNames(dog))   // ['name']
console.log(Object.getOwnPropertyNames(Dog))   // 含 'species'、'length' 等
```

### `type()`

返回对象的类型（对象是通过哪个类创建的）：

```python
dog = Dog("Buddy")

print(type(dog))       # <class '__main__.Dog'>
print(type(Dog))       # <class 'type'>
print(type(123))       # <class 'int'>
print(type("hello"))   # <class 'str'>
```

JavaScript 类比：

```js
const dog = new Dog("Buddy")

console.log(dog.constructor)           // [class Dog]
console.log(typeof dog)                // "object"（对自定义类信息有限）
console.log(Object.getPrototypeOf(dog) === Dog.prototype)  // true
console.log(typeof 123)                // "number"
console.log(typeof "hello")            // "string"
```

### `isinstance()`

判断对象是否是指定类（或其子类）的实例：

```python
dog = Dog("Buddy")

print(isinstance(dog, Dog))      # True
print(isinstance(dog, Animal))   # True（Dog 继承 Animal）
print(isinstance(dog, str))      # False

# 支持元组形式，判断是否为多个类型之一
print(isinstance(dog, (Dog, Cat)))   # True
print(isinstance(123, (str, int)))   # True
```

JavaScript 类比：

```js
const dog = new Dog("Buddy")

console.log(dog instanceof Dog)     // true
console.log(dog instanceof Animal)  // true
console.log(dog instanceof String)  // false

// 多类型之一：自己写或
console.log([Dog, Cat].some((C) => dog instanceof C))  // true
console.log(typeof 123 === "string" || typeof 123 === "number")  // true
```

**与 `type()` 的区别：** `isinstance()` 会考虑继承关系，`type()` 不会。

> **说明：** JavaScript 的 `instanceof` 会沿原型链判断，类似 `isinstance`；`typeof` 对自定义类几乎都返回 `"object"`，不能当 `type()` 用。

### `issubclass()`

判断一个类是否是另一个类的子类：

```python
print(issubclass(Dog, Animal))   # True
print(issubclass(Dog, Dog))      # True（类是自己的子类）
print(issubclass(Animal, Dog))   # False

# 支持元组
print(issubclass(Dog, (Animal, str)))  # True
```

**JavaScript 无直接对应。** 无内置 `issubclass`；可沿原型链判断：

```js
const isSubclass = (Sub, Base) =>
  Sub === Base || Sub.prototype instanceof Base

console.log(isSubclass(Dog, Animal))  // true
console.log(isSubclass(Dog, Dog))     // true
console.log(isSubclass(Animal, Dog))  // false
```

### `dir()`

返回对象的所有属性和方法列表（包括继承的）：

```python
dog = Dog("Buddy")

# 查看对象的所有属性和方法
print(dir(dog))
# ['__class__', '__delattr__', ..., 'name', 'species']

# 查看类的所有属性和方法
print(dir(Dog))

# 不带参数时，返回当前作用域的所有名称
print(dir())
```

**JavaScript 无直接对应。** 无单函数列出“含继承的全部成员”；可拼自有属性与原型链上的键：

```js
const dirLike = (obj) => {
  const keys = new Set()
  let cur = obj
  while (cur && cur !== Object.prototype) {
    Object.getOwnPropertyNames(cur).forEach((k) => keys.add(k))
    cur = Object.getPrototypeOf(cur)
  }
  return [...keys]
}

const dog = new Dog("Buddy")
console.log(dirLike(dog))
```

### `vars()`

返回对象的 `__dict__` 属性，即对象的属性字典：

```python
dog = Dog("Buddy")

print(vars(dog))        # {'name': 'Buddy'}
print(vars(Dog))        # 类的 __dict__
print(dog.__dict__)     # 等同于 vars(dog)

# 不带参数时，等同于 locals()
print(vars())
```

**JavaScript 无直接对应。** 近似写法是枚举实例自有可枚举属性：

```js
const dog = new Dog("Buddy")
console.log({ ...dog })  // { name: 'Buddy' }（视属性是否可枚举而定）
```

### `getattr()`

获取对象的属性值，属性不存在时可返回默认值。**会沿着继承链查找属性（包括实例属性、类属性、父类属性）：**

```python
class Animal:
  species = "Animal"

  def speak(self):
    return "Some sound"

class Dog(Animal):
  def __init__(self, name):
    self.name = name

dog = Dog("Buddy")

# 查找实例属性
print(getattr(dog, "name"))           # Buddy

# 查找类属性
print(getattr(dog, "species"))        # Animal（继承自父类）

# 查找父类方法
print(getattr(dog, "speak")())        # Some sound

# 属性不存在时，提供默认值
print(getattr(dog, "age", 3))         # 3（默认值）

# 等价于
dog.name
dog.species
dog.speak()
```

JavaScript 类比：

```js
class Animal {
  static species = "Animal"

  speak() {
    return "Some sound"
  }
}

class Dog extends Animal {
  constructor(name) {
    super()
    this.name = name
  }
}

const dog = new Dog("Buddy")

const getattr = (obj, key, defaultValue) =>
  key in obj ? obj[key] : defaultValue

console.log(dog.name)                    // Buddy
console.log(getattr(dog, "age", 3))      // 3
console.log(dog.speak())                 // Some sound
// 注意：static species 默认不在实例上，需 Dog.species / Animal.species
```

### `setattr()`

设置对象的属性值，属性不存在时会创建。**如果父类定义了描述符（如 `@property.setter`）或 `__setattr__` 方法，会遵循继承链上的这些机制：**

```python
dog = Dog("Buddy")

setattr(dog, "age", 3)
print(dog.age)            # 3

# 等价于
dog.age = 3

# 可以动态设置属性名
attr_name = "breed"
setattr(dog, attr_name, "Golden Retriever")
print(dog.breed)          # Golden Retriever
```

JavaScript 类比：

```js
const dog = new Dog("Buddy")

dog.age = 3
console.log(dog.age)  // 3

const attrName = "breed"
dog[attrName] = "Golden Retriever"
console.log(dog.breed)  // Golden Retriever
```

### `hasattr()`

判断对象是否有指定属性。**会检查继承链上的所有属性：**

```python
dog = Dog("Buddy")

# 实例属性
print(hasattr(dog, "name"))       # True

# 继承的类属性
print(hasattr(dog, "species"))    # True（继承自 Animal）

# 继承的方法
print(hasattr(dog, "speak"))      # True（继承自 Animal）

# 不存在的属性
print(hasattr(dog, "age"))        # False

# 常用于安全地访问属性前进行检查
if hasattr(dog, "name"):
  print(dog.name)
```

JavaScript 类比：

```js
const dog = new Dog("Buddy")

console.log("name" in dog)    // true
console.log("speak" in dog)   // true（在原型上）
console.log("age" in dog)     // false

if ("name" in dog) {
  console.log(dog.name)
}
```

### `delattr()`

删除对象的属性：

```python
dog = Dog("Buddy")

# 添加一个属性
setattr(dog, "age", 3)
print(dog.age)            # 3

# 删除属性
delattr(dog, "age")
# print(dog.age)          # AttributeError!

# 等价于
del dog.age
```

JavaScript 类比：

```js
const dog = new Dog("Buddy")

dog.age = 3
console.log(dog.age)  // 3

delete dog.age
// console.log(dog.age)  // undefined
```

类型标注（Type Hints）在运行时**不强制约束**，主要为静态检查工具（如 Pyright、mypy）和 IDE 提供信息。建议在 VS Code / Cursor 中开启 `python.analysis.typeCheckingMode`。

| Python | TypeScript 对应 |
| ------ | --------------- |
| `x: int` / `def f(a: int) -> str` | `let x: number` / `(a: number) => string` |
| `Optional[T]` / `T \| None` | `T \| null`（另有 `undefined`） |
| `Union[A, B]` / `A \| B` | `A \| B` |
| `list[T]` / `dict[K, V]` | `T[]` / `Array<T>` / `Record<K, V>` / `Map` |
| `Any` | `any` |
| `TypeAlias` / `Vector = list[float]` | `type Vector = number[]` |
| `NoReturn` | `never` |
| `Self` | 方法返回 `this` |
| `Generic[T]` / `TypeVar` | `class Stack<T>` / 泛型函数 |
| `Callable[[A], R]` | `(a: A) => R` |
| `TypedDict` | `interface` / `type` 对象形状 |
| `# type: ignore` | `// @ts-ignore` / `// @ts-expect-error` |

## 为什么需要类型标注

```python
# 问题：参数类型不明确
def add(a, b):
  return a + b

# 调用者不知道应该传什么类型
add(1, 2)        # 3
add("1", "2")    # "12"  —— 这也是合法的，但可能不是预期行为
add([1], [2])    # [1, 2]  —— 同样合法

# 没有类型提示，难以在编码时发现错误
```

TypeScript 类比：

```ts
// 未标注时，参数隐式为 any（视编译选项而定）
const add = (a, b) => a + b

add(1, 2)           // 3
add("1", "2")       // "12"
add([1], [2])       // [1, 2]
```

> **说明：** Python 类型标注默认不改变运行时行为；TypeScript 在编译期检查，编译后类型会被擦除。

## 基础类型标注

### 变量类型标注

```python
# 声明变量的类型
name: str = "Alice"
age: int = 25
pi: float = 3.14
is_active: bool = True

# 没有初始值
value: int
value = 10

# Python 是动态语言，类型标注不会强制约束
x: int = "hello"  # 不会报错，但类型检查工具会提示
```

TypeScript 类比：

```ts
const name: string = "Alice"
const age: number = 25
const pi: number = 3.14
const isActive: boolean = true

// 先声明再赋值
let value: number
value = 10

// 开启严格检查时，下面会报错（编译期）
// const x: number = "hello"
```

> **说明：** Python 的 `int` / `float` 在 TypeScript 里通常都对应 `number`；大整数可用 `bigint`。

### 函数类型标注

```python
def greet(name: str, age: int) -> str:
  """函数参数和返回值的类型标注"""
  return f"{name} 今年 {age} 岁"

# 调用
greet("Alice", 25)        # 正确
greet("Alice", "25")      # 运行不会报错，但类型检查会警告
```

TypeScript 类比：

```ts
const greet = (name: string, age: number): string => {
  return `${name} 今年 ${age} 岁`
}

greet("Alice", 25)        // 正确
// greet("Alice", "25")   // 编译报错
```

```python
from typing import NoReturn

def exit_program() -> NoReturn:
  """表示函数永远不会正常返回"""
  import sys
  sys.exit(1)
```

TypeScript 类比：

```ts
const exitProgram = (): never => {
  throw new Error("exit")
}
```

## 常用复合类型

### Optional 和 Union

```python
from typing import Optional, Union

# Optional：值可以是某个类型，也可以是 None
def find_user(user_id: int) -> Optional[str]:
  """返回用户名，找不到时返回 None"""
  if user_id <= 0:
    return None
  return f"User_{user_id}"

# Union：值可以是多种类型之一
def parse_value(value: str) -> Union[int, float, str]:
  """尝试将字符串转换为数字，失败则返回原字符串"""
  try:
    if "." in value:
      return float(value)
    return int(value)
  except ValueError:
    return value
```

TypeScript 类比：

```ts
// Optional / None → T | null（也常见 T | undefined）
const findUser = (userId: number): string | null => {
  if (userId <= 0) {
    return null
  }
  return `User_${userId}`
}

// Union
const parseValue = (value: string): number | string => {
  const n = Number(value)
  if (Number.isNaN(n)) {
    return value
  }
  return n
}
```

> **说明：** Python 3.10+ 可用 `str | None`、`int | float | str` 代替 `Optional` / `Union`。TypeScript 的 `null` 与 `undefined` 是两个不同空值，对应时需按约定选择。

### 容器类型

```python
from typing import List, Dict, Tuple, Set

# 列表：元素类型
scores: List[int] = [85, 90, 78]
names: List[str] = ["Alice", "Bob", "Charlie"]

# 字典：键类型, 值类型
student_scores: Dict[str, int] = {
  "Alice": 85,
  "Bob": 90,
}

# 元组：固定长度，每个位置类型可不同
point: Tuple[int, int] = (10, 20)
person: Tuple[str, int, bool] = ("Alice", 25, True)

# 集合：元素类型
tags: Set[str] = {"python", "typing", "type-hints"}
```

TypeScript 类比：

```ts
const scores: number[] = [85, 90, 78]
const names: string[] = ["Alice", "Bob", "Charlie"]

const studentScores: Record<string, number> = {
  Alice: 85,
  Bob: 90,
}

// 固定长度元组
const point: [number, number] = [10, 20]
const person: [string, number, boolean] = ["Alice", 25, true]

const tags: Set<string> = new Set(["python", "typing", "type-hints"])
```

> **说明：** Python 3.9+ 可直接写 `list[int]`、`dict[str, int]`、`tuple[int, int]`、`set[str]`，不必从 `typing` 导入大写形式。

### Any 和 类型别名

```python
from typing import Any, TypeAlias

# Any：任意类型，相当于没有类型约束
def log_data(data: Any) -> None:
  print(f"数据: {data}")

# 类型别名，让复杂类型更易读
Vector: TypeAlias = list[float]
Matrix: TypeAlias = list[list[float]]

def dot_product(v1: Vector, v2: Vector) -> float:
  """计算两个向量的点积"""
  return sum(a * b for a, b in zip(v1, v2))
```

TypeScript 类比：

```ts
const logData = (data: any): void => {
  console.log(`数据: ${data}`)
}

type Vector = number[]
type Matrix = number[][]

const dotProduct = (v1: Vector, v2: Vector): number => {
  return v1.reduce((sum, a, i) => sum + a * v2[i], 0)
}
```

## 类与自定义类型

```python
from typing import Self

class Point:
  def __init__(self, x: float, y: float) -> None:
    self.x = x
    self.y = y

  def move(self, dx: float, dy: float) -> Self:
    """返回移动后的新点"""
    return Point(self.x + dx, self.y + dy)

  def distance_to(self, other: "Point") -> float:
    """计算到另一个点的距离"""
    return ((self.x - other.x) ** 2 + (self.y - other.y) ** 2) ** 0.5

# 使用
p1 = Point(0, 0)
p2 = Point(3, 4)
print(p1.distance_to(p2))  # 5.0
```

TypeScript 类比：

```ts
class Point {
  constructor(public x: number, public y: number) {}

  move(dx: number, dy: number): this {
    return new Point(this.x + dx, this.y + dy) as this
  }

  distanceTo(other: Point): number {
    return ((this.x - other.x) ** 2 + (this.y - other.y) ** 2) ** 0.5
  }
}

const p1 = new Point(0, 0)
const p2 = new Point(3, 4)
console.log(p1.distanceTo(p2))  // 5
```

> **说明：** Python 的 `Self` 表示「当前类或其子类实例」；TypeScript 方法里的 `this` 返回类型有类似作用。前向引用可用字符串注解 `"Point"`，TypeScript 因类声明提升通常不需要。

## 泛型

```python
from typing import TypeVar, Generic

T = TypeVar("T")

class Stack(Generic[T]):
  """泛型栈，可以存储任意类型的元素"""

  def __init__(self) -> None:
    self._items: list[T] = []

  def push(self, item: T) -> None:
    self._items.append(item)

  def pop(self) -> T:
    if not self._items:
      raise IndexError("栈为空")
    return self._items.pop()

  def peek(self) -> T | None:
    if not self._items:
      return None
    return self._items[-1]

# 使用
int_stack: Stack[int] = Stack()
int_stack.push(1)
int_stack.push(2)
print(int_stack.pop())  # 2

str_stack: Stack[str] = Stack()
str_stack.push("hello")
# str_stack.push(123)  # 类型检查会警告
```

TypeScript 类比：

```ts
class Stack<T> {
  private items: T[] = []

  push(item: T): void {
    this.items.push(item)
  }

  pop(): T {
    if (this.items.length === 0) {
      throw new Error("栈为空")
    }
    return this.items.pop() as T
  }

  peek(): T | null {
    if (this.items.length === 0) {
      return null
    }
    return this.items[this.items.length - 1]
  }
}

const intStack: Stack<number> = new Stack()
intStack.push(1)
intStack.push(2)
console.log(intStack.pop())  // 2

const strStack: Stack<string> = new Stack()
strStack.push("hello")
// strStack.push(123)  // 编译报错
```

## Callable 和 回调函数

```python
from typing import Callable

def execute_callback(
  callback: Callable[[int, int], int],
  a: int,
  b: int,
) -> int:
  """执行回调函数"""
  return callback(a, b)

# 使用
result = execute_callback(lambda x, y: x + y, 3, 5)
print(result)  # 8
```

TypeScript 类比：

```ts
const executeCallback = (
  callback: (a: number, b: number) => number,
  a: number,
  b: number,
): number => {
  return callback(a, b)
}

const result = executeCallback((x, y) => x + y, 3, 5)
console.log(result)  // 8
```

## 应用场景

### 1. API 接口定义

```python
from typing import TypedDict

class UserResponse(TypedDict):
  """API 返回的用户数据结构"""
  id: int
  name: str
  email: str
  is_active: bool

def get_user(user_id: int) -> UserResponse:
  return {
    "id": user_id,
    "name": "Alice",
    "email": "alice@example.com",
    "is_active": True,
  }
```

TypeScript 类比：

```ts
interface UserResponse {
  id: number
  name: string
  email: string
  is_active: boolean
}

const getUser = (userId: number): UserResponse => {
  return {
    id: userId,
    name: "Alice",
    email: "alice@example.com",
    is_active: true,
  }
}
```

> **说明：** `TypedDict` 描述的是「长得像字典的结构」；TypeScript 的 `interface` / `type` 描述对象形状。二者都不等于运行时的 class 实例。

### 2. 配合 IDE 获得智能提示

类型标注让 IDE 可以提供：

- 自动补全
- 参数提示
- 类型错误高亮

```python
from typing import Any

class Database:
  def connect(self, host: str, port: int = 5432) -> "Connection":
    ...

  def query(self, sql: str) -> list[dict[str, Any]]:
    ...

db = Database()
conn = db.connect("localhost")  # IDE 会提示 port 参数
```

TypeScript 类比：

```ts
class Database {
  connect(host: string, port: number = 5432): Connection {
    // ...
    return {} as Connection
  }

  query(sql: string): Array<Record<string, any>> {
    // ...
    return []
  }
}

const db = new Database()
const conn = db.connect("localhost")  // IDE 会提示 port 参数
```

## 忽略类型检查

有时某些代码难以标注或不需要检查，可以使用 `# type: ignore` 忽略：

```python
# 忽略整行的类型检查
data = some_dynamic_library.load()  # type: ignore

# 有具体错误码时，可以指定忽略特定错误
x: int = "hello"  # type: ignore[assignment]
```

TypeScript 类比：

```ts
// 忽略下一行
// @ts-ignore
const data = someDynamicLibrary.load()

// 更推荐：明确「预期有错」
// @ts-expect-error 赋值类型不匹配
const x: number = "hello"
```

**注意：** 应该尽量少用，只在必要时使用。
